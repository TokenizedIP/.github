# TIPL public repositories
Our goal is to help our member projects build value, and maximize contributions from users and AI. We provide the Tokenized IP License, the TIPL.fun launchpad, treasury governance, and related tools. This gives our member projects:

* **IP value:** Intellectual property rights tied to crypto tokens
* **Governance:** Manage token flows to build confidence and value
* **Economics:** Reward contributors and pay compute costs
* **Automation:** Refinement and merging of AI and human contributions

Learn more in the [TIPL.fun documentation](https://www.tipl.fun/docs).

The IP in these repositories is controlled by the Tokenized IP License and linked to the TIPL token.
